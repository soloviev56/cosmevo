# Космическая эволюция

Электронное пособие для магистрантов-теоретиков: физика усложнения
материи во Вселенной от Большого взрыва до пределов разума в далёком
будущем, с исполняемым кодом на Python (NumPy, SciPy, SymPy, Astropy).
Устроено так же, как пособие «Геометрические методы в физике» (GMPh).

## Устройство репозитория

| Путь | Что там |
|---|---|
| `topics.yml` | **карта тем**: все темы пособия, уровень, статус, зависимости, содержание |
| `methods/`, `evolution/` | статьи (`.qmd`): ось «аппарат» и ось «этапы космической эволюции» |
| `conventions.qmd` | единицы, обозначения, метки статуса [У]/[Г]/[С] |
| `src/cosmevo/` | вычислительное ядро: общие функции для статей |
| `tests/` | тесты ядра, конвенций и карты тем |
| `scripts/topics.py` | сборка карты тем и проверка зависимостей |
| `filters/topics.lua` | блок «Уровень и связи» в начале каждой статьи |
| `_macros.html` | общие LaTeX-макросы (`\dd`, `\Mpl`, `\Msun`, …) |
| `styles.css` | оформление меток статуса |
| `notes/` | личные черновики (не публикуются, в `.gitignore`) |

## Как работать

```bash
conda env create -f environment.yml   # один раз
conda activate cosmevo
python -m pytest                      # тесты ядра
quarto preview                        # сайт с автообновлением в браузере
quarto render                         # полная сборка в _site/
```

## Новая статья

Все темы, их уровень, статус и зависимости перечислены в `topics.yml`.
Статья темы кладётся в каталог её раздела (например, тема `bbn` раздела
`evolution/early` — в `evolution/early/bbn.qmd`) и указывает в заголовке
только идентификатор темы:

```yaml
---
title: "Первичный нуклеосинтез"
topic: bbn          # идентификатор из topics.yml
order: 5            # порядок в оглавлении раздела
---
```

Уровень, статус и зависимости в статье не повторяются: они берутся из
`topics.yml`. Новая тема сначала добавляется туда.

Сборка остановится, если:
- тема ссылается на несуществующую тему или зависит от темы более высокого уровня;
- у темы неизвестный статус (допустимы У, Г, С);
- в зависимостях есть цикл;
- статья лежит не в каталоге своего раздела или её темы нет в `topics.yml`;
- код в статье завершился с ошибкой.

Функции, нужные в нескольких статьях, добавляются в `src/cosmevo/` вместе с тестами.

## Ежедневная работа

Как в GMPh: раз в сутки таймер systemd может запускать Claude Code без
участия человека (`scripts/daily/run.sh`), и он по инструкции
`scripts/daily/prompt.md` либо исправляет замечания автора, либо пишет и
публикует следующую порцию тем. Отчёты и замечания — в локальном файле
`journal.md` (в репозиторий не входит), логи — в `logs/`.

```bash
scripts/daily/install.sh            # включить таймер
scripts/daily/install.sh --remove   # выключить
systemctl --user start cosmevo-daily   # запустить порцию вне расписания
```
